# Style guide

The visual direction is intentionally broad at this stage. Preserve room for the design to mature alongside real project material.

## Principles

- Clean, modern, technical, and research-oriented.
- Research-paper clarity combined with an engineering portfolio and a modern technical product page.
- Real project media should carry more weight than decorative imagery.
- Restrained, highly readable typography with a clear hierarchy.
- Minimal unnecessary decoration, gradients, animation, and interface chrome.
- Responsive layouts that work without horizontal clipping.
- Semantic structure, visible keyboard focus, sufficient contrast, useful alt text, and reduced-motion respect.
- No generic startup slogans, invented metrics, stock portraits, or AI-style filler.

## Content presentation

Use concise language and evidence-led captions. Keep technical diagrams legible. Preserve aspect ratios. Do not use visual polish to overstate the maturity or certainty of a project.

Exact colours, fonts, logo, card system, and motion language are not finalised. When a future project page introduces a reusable visual pattern, extend the system deliberately and avoid redesigning unrelated pages.
