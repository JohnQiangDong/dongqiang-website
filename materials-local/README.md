# Local-only materials

This directory is ignored by Git except for this README. Use it for very large raw video, original camera files, high-resolution masters, temporary exports, duplicates, private working files, or other material that should not be pushed to GitHub.

Create project subfolders locally as needed, for example `materials-local/haptic-robot-learning/`. Files here are never published automatically. Copy only reviewed, processed derivatives into the matching `public/media/projects/<project-slug>/` folder.
