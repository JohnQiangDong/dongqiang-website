# Project source materials

This directory is a review workspace for project-specific source material. Add notes, documents, photos, videos, figures, and links to the matching project folder while developing one page at a time.

Material here is not automatically public. A file must be reviewed, selected, checked for permission and confidentiality, prepared for the web, and copied to `public/media/` before the site can serve it. Use `materials-local/` instead for very large, private, duplicate, or temporary files that should not enter Git.

Project folder names use lowercase kebab-case. Do not rename raw files merely to make this folder tidy; meaningful renaming happens when a selected derivative is prepared for publication.
